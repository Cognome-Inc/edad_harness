## Context

The only way to run the harness from a target repo today is
`export PYTHONPATH=/path/to/this/repo`, documented in QUICKSTART with the comment
"until the package is installable". That works on the machine it was typed on. The
harness is about to be used against ai-sniffer by a team, and its own thesis — a
gate's verdict is a property of the commit, not of whatever was installed that day —
currently covers pytest, ruff and PyYAML through `requirements-gate.txt` and does not
cover the harness itself.

`pyproject.toml` already exists and carries the pytest and ruff tables. It has no
`[build-system]`, no `[project]` and no `[tool.setuptools]`. That is why every test in
the frozen file is red at base: each one parses the file with `tomllib` (stdlib on
3.12 and 3.13) and asserts on a table that is not there. `QUICKSTART.md` mentions
`PYTHONPATH` exactly once, at line 17.

Two things were established before this ticket was written:

- The install works end to end from the metadata below (D4, proven by hand — see
  *Before approving*). The loose `PyYAML>=6.0` resolved to **6.0.3** in a fresh venv,
  which the gate refuses; that is why QUICKSTART's `pip install -r
  requirements-gate.txt` line stays *first* and pins 6.0.2 before the harness is
  installed. Do not reorder the two lines.
- Adding `requires-python = ">=3.12"` changes ruff's inferred target and raised six
  `UP017` findings in `edad/*.py` — outside this ticket's scope, so `full_gate` would
  have been unwinnable. `[tool.ruff] target-version = "py312"` is now pinned and the
  six findings are fixed on main, ahead of this ticket. Nothing about that is the
  agent's to do.

## Goal

`pyproject.toml` declares a setuptools-built distribution `edad-harness` `0.1.0`
whose only package is `edad` and whose only dependency is a loose PyYAML, with no
console script. QUICKSTART's install section shows `pip install
git+https://github.com/Cognome-Inc/edad_harness@v0.1.0` as the default for a target's
team and `pip install -e /path/to/edad_harness` for harness developers, and the word
`PYTHONPATH` appears nowhere in the file.

## Required interface

All of it is pinned by `tests/test_packaging.py`; read it first. Exact values, because
the tests compare them by equality:

**`pyproject.toml`** — add three tables. Leave the existing `[tool.pytest.ini_options]`
and `[tool.ruff*]` tables exactly as they are.

- `[build-system]`: `requires = ["setuptools>=68"]`,
  `build-backend = "setuptools.build_meta"`.
- `[project]`: `name = "edad-harness"`, `version = "0.1.0"`,
  `requires-python = ">=3.12"`, `dependencies = ["PyYAML>=6.0"]`. No
  `[project.scripts]`, no `[project.gui-scripts]`. Nothing is added to
  `edad/__init__.py`; the version lives here only.
- `[tool.setuptools]`: `packages = ["edad"]`. Named rather than discovered, because
  flat-layout auto-discovery would see `tests/` and `docker_tests/` beside `edad/` and
  refuse.

**`QUICKSTART.md`** — in the Install section, replace the `export PYTHONPATH=…` line
with the pinned form, keeping `pip install -r requirements-gate.txt` above it, and add
the editable form for harness developers:

    pip install -r requirements-gate.txt      # the gate's pins, exact
    pip install git+https://github.com/Cognome-Inc/edad_harness@v0.1.0   # the harness, pinned

    Developing the harness itself? Install your checkout editable instead, so
    edits are live: `pip install -e /path/to/edad_harness`.

The test looks for the literal `pip install git+https://github.com/Cognome-Inc/edad_harness@v<X.Y.Z>`
(and checks `<X.Y.Z>` equals `[project].version`), the literal `pip install -e `, and
the absence of `PYTHONPATH` from the **whole file**. The prose around them is yours,
in the file's existing register.

## Out of scope

- **Both Dockerfiles.** The agent image runs the target's tests, not `edad`; the egress

- **Tagging `v0.1.0`** (D6). A tag is repository state the gate cannot see from a
  worktree; the operator tags the merge commit — see *At merge*.
- **The harness version in evidence records**, and with it who bumps `0.1.0` and
  when. The next ticket; needs its own grill.
- **A console script.** Deferred in the grill; `python3 -m edad.*` stays the only
  spelling every doc, skill and the T017 host allowlist knows.
- **`requirements-gate.txt`.** The exact PyYAML pin stays there and only there.
