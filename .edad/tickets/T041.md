## Context

T031's post-build review found four ways a test-review round can record
something untrue.

- **Hashed late (D32).** `cmd_tests` calls `gate.frozen_hashes_now` *after*
  `run_reviewer` returns. A test edited while the reviewer runs gets a pass
  stamped on bytes the reviewer never saw, and `gate.review_problems` accepts
  that pass. Read each frozen file's bytes once, and build the artifact and
  the round's `frozen` hashes from those same bytes. Hashing just before the
  launch was rejected, because it leaves a window between the read and the
  hash.
- **Rounds that could not run (D33).** These extend T031's "a reviewer that
  exits non-zero spends no round" rule:
  - **A missing `claude`** raises `FileNotFoundError` today. Python exits 1,
    the same code as a failed round, with a traceback.
  - **A hung reviewer** blocks forever.
  - **A ticket with `frozen: []`** launches a reviewer on nothing and spends
    a round, which approve then refuses anyway.

  Each of these becomes a `gate.die`. Counting a timeout as a failed round
  was rejected, because it burns a round on an infrastructure fault.
- **Corrupt record overwritten (D34).** An unreadable review record, or one
  whose `rounds` is not a list, is read as empty and overwritten with
  `{"rounds": [new]}`. That destroys the history that is supposed to be
  append-only. `gate.read_record` returns `None` for both a missing record and
  an unreadable one, so tell them apart here by whether
  `gate.hash_record_path(root, tid, "review")` exists. Approve's reader is
  deliberately unchanged: there, a corrupt record still counts as no record.
  Moving the record aside and starting at round 1 was rejected: that is a
  reset by deletion, which review-loops D27 rejects.

**Sealing the launch (D37–D39, from T040's post-build review).** Three ways
the caller can still reach or break the isolated reviewer:

- **Stdin (D37).** `run_reviewer` inherits the caller's stdin, and `claude -p`
  reads piped stdin into its prompt. Measured 2026-10-28 (`claude` 2.1.280):
  from an empty temp dir with `--system-prompt` and `--tools ""`, a piped line
  was quoted back word for word, and with stdin from `/dev/null` nothing from
  the caller arrived.
- **Encoding (D38).** `text=True` decodes with the locale's encoding, so a
  non-ASCII reply raises `UnicodeDecodeError` under `LANG=C`.
- **`TMPDIR` (D39).** T040's empty directory comes from the system temp
  location. A `TMPDIR` inside a project puts the reviewer back inside that
  project, with no error. Nothing in the harness sets `TMPDIR`, and the
  night's container uses `/tmp`.

Rejected: `errors="replace"` (it quietly patches a garbled reply into a
plausible one); a fixed `dir=` of the module's own (nowhere is outside every
project on every machine, and it bypasses `TMPDIR`); `.claude/` as a project
marker (`~/.claude` is user-level and loads anyway).

**How the tests reach the round (seam S5).** The tests drive `review.main()`
with `sys.argv`, and the repo is a temp directory reached through `EDAD_REPO`.
Approve is always replaced.

- **D32 and the no-frozen-files test** replace `review.run_reviewer` with a
  one-argument callable. In D32's test, that callable edits a frozen file
  while it is "reading".
- **The missing-binary and timeout tests** leave the real `run_reviewer` in
  place and fake `subprocess.run`, which raises `FileNotFoundError` or
  `subprocess.TimeoutExpired`.
- **D37–D39's tests** also leave the real `run_reviewer` in place and fake
  `subprocess.run`. They read the `stdin` and `encoding` it is given, and D39's
  points `tempfile.tempdir` inside a directory holding `.git` or `CLAUDE.md`.
  Every fake takes `**kwargs`, so T040's `cwd=` and the new keywords pass
  through.

An exception that escapes `review.main()` is turned into its type name, so a
crash fails an assertion rather than the test run. No test launches a model,
and none shells to git.

## Goal

A round that could not run, or had nothing to review, writes nothing and
spends no round. A round that did run records exactly the bytes its reviewer
was shown. A corrupt record stops the command instead of being overwritten.
The reviewer cannot read what the caller pipes in, its output is read as UTF-8
whatever the locale, and it never starts inside a project because of `TMPDIR`.
The skills and session messages name the commands that work since T029.

## Required interface

All in `edad/review.py`. Keep T040's `run_reviewer(argv)` and
`reviewer_argv(prompt)` signatures. Each refusal goes through `gate.die()`,
so it exits 2 and writes nothing.

- **Bytes once.** In `cmd_tests`, read each frozen file once as bytes. The
  artifact is built from those bytes, decoded as UTF-8. The round's `frozen`
  is `{path: sha256 hexdigest of those bytes}`, in the same shape
  `gate.frozen_hashes_now` gives, so `gate.review_problems` reads it
  unchanged.
- **Missing binary.** In `run_reviewer`, catch `FileNotFoundError` from
  `subprocess.run` and refuse with a message that names the binary
  (`argv[0]`, i.e. `claude`).
- **Timeout.** In `run_reviewer`, pass `timeout=900` to `subprocess.run`,
  from a module constant. Catch `subprocess.TimeoutExpired` and refuse with a
  message containing `900`.
- **No frozen files.** In `cmd_tests`, before anything launches, refuse with
  approve's own message, which contains `ticket declares no frozen files`.
- **Corrupt record.** In `cmd_tests`, before anything launches, refuse when
  the review record's path exists and either `gate.read_record` returns
  `None` (unreadable, or not a JSON object) or its `rounds` is not a list.
  The message names the file (`<T>.review.json`), and the file is left
  byte-for-byte as it was.

- **Stdin closed.** In `run_reviewer`, pass `stdin=subprocess.DEVNULL`.
- **UTF-8.** In `run_reviewer`, pass `encoding="utf-8"`. Keep
  `capture_output=True` and `text=True`: T031's frozen
  `test_a_reviewer_that_fails_to_run_uses_up_no_round` returns real output
  only when both are passed.
- **Temp dir inside a project.** In `run_reviewer`, inside the
  `TemporaryDirectory` block and before launching, look for `.git` or
  `CLAUDE.md` in the resolved directory and every directory above it. If one
  exists, refuse with a message that names the marker found (for example its
  path). Refusing inside the block still removes the directory.

The constants' names and the wording, apart from the substrings above, are
yours to choose.
